# OSTF 5.0.0 — Change Log

## v5.0.0 · 2026-11-22

- Publishes the two official file forms: `.ostf` standalone JSON Score and `.ostfp` ZIP-based multi-file Project, with a separately versioned Package Manifest 1.0.
- Inherits all published 4.3 Score Core musical definitions unchanged; the exact Score `version` is now `5.0.0` for newly produced Score5 files.
- Publishes Production Session 0.3.0 for Score5 byte-pinned mixer/track/audio/asset/plugin automation state, based on adopted Production0.2.
- Publishes Distributed Session 0.3 Snapshot/Event profile pinned to Score5 original byte identity, based on adopted Distributed0.2.
- Defines transport-neutral Plugin Context 1.0 for VST3/AU/CLAP/M4L/AI/DAW partial reads and atomic host-reviewed edit proposals.
- Includes precise version-family selection, immutable Score hashing, safe ZIP paths, asset binding, loss and migration policies.
- Delivers English/Japanese integrated manuals, comprehensive field references and categorized 25 `.ostf` plus 11 `.ostfp` sample files under a 100-file GitHub release layout.
- Execution certification, independent parsers, host interoperability and signoff are not stated as completed.
